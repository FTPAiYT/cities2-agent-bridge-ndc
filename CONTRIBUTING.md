# Contributing

Try the released package with your own installed copy of Cities: Skylines II. Share what your agent builds, and report reproducible failures in Issues. Include the game build, bridge release, agent/tools, and the command or action that failed. Review logs before attaching them; omit private paths, transcripts, credentials and saves unless deliberately sharing them.

Source is included for inspection. See DEVELOPMENT.md for local builds and offline tests; you must supply your own game assemblies. Never commit game DLLs, city saves, personal journals or machine-specific files.

This is an experimental project. File-copy success and passing offline tests do not establish that a rebuilt DLL works in-game. Report what you tested and what remains unverified. No broad open-source license has been selected; see SHARING.md.
